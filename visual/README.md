# 생각 씨앗 시각화 챌린지 (초2~초5)

학원생이 **하루 한 문제**를 그림·수직선·막대 도식·표로 생각을 꺼내 풀고, 모범 시각화 풀이와 비교하는 4주(20일) 프로그램입니다.
설치 없이 브라우저에서 바로 동작합니다. (휴대폰·태블릿 우선)

## 하루 학습 흐름 (6단계)
1. **문제 읽기** – 형광펜으로 *알고 있는 것*·*구하는 것* 표시, 구하는 것을 내 말로 쓰기
2. **혼자 생각하기 (15분)** – 그림판(펜·곧은 선·네모·지우개, 빈 종이/모눈/수직선/막대/표 바탕) 또는 공책 사진 올리기. 힌트는 3분 뒤에 열림
3. **식과 답** – 그림을 보고 식 세우기, 답 확인(기회 2번 — 틀려도 다음 단계로 갈 수 있음)
4. **풀이 인증** – 인증하면 내 풀이가 잠기고 *인증 카드(이미지)*가 만들어짐 → 저장/카톡 공유
5. **모범 시각화 풀이** – ① 문제 이해 → ② 그림/수직선/표 → ③ 식과 답 + 선생님 한마디, 한 단계씩 열기
6. **다시 살펴보기** – 내 그림과 모범 풀이를 나란히 비교, 자기 점검 + 알게 된 점 한 줄

정답을 보기 전에 반드시 "내 생각"이 먼저 남도록, 인증 전에는 모범 풀이가 열리지 않습니다.

## 화면
- **처음 화면**: 학생 등록(이름·학년), 한 기기에 여러 학생 가능
- **4주 생각 달력**: 새싹이 씨앗 → 꽃 핀 나무로 자람, 연속 도전·한 번에 해결·생각한 시간
- **완주 카드**: 20문제를 끝내면 이미지로 저장
- **선생님 메뉴** (처음 비밀번호 `0000`, 설정에서 변경)
  - 학생 현황: 날짜별 결과·시간·힌트 사용·알게 된 점, 풀이 다시 보기, "오늘 1문제 더 열기"
  - 문제·풀이 보기: 학년별 20문제와 모범 풀이 전체
  - 학습지 인쇄: 학년·주차별 종이 학습지 (+ 답지)
  - 설정·백업: 하루 1문제 제한 켜기/끄기, 학원 이름, 백업 저장/불러오기(그림 포함)

## 문제 바꾸기
`problems.js`만 고치면 됩니다. 파일 맨 위에 항목 설명이 있습니다.
학년별 주제: 초2 덧뺄셈·곱셈·길이와 시간·규칙 / 초3 나눗셈·곱셈·단위·분수와 소수 /
초4 큰 수·분수 덧뺄셈·소수와 각도·규칙 / 초5 약수와 배수·이분모 분수·곱셈과 평균·넓이와 대응

## 알아 둘 점
- 기록은 **그 기기의 브라우저**에 저장됩니다(서버 없음). 학생이 집에서 풀면 인증 카드를 카페·카톡으로 받아 확인하세요.
- 브라우저 기록을 지우면 기록도 사라지니, 선생님 메뉴에서 백업을 받아 두세요.

## 실행
저장소 루트에서 `python server.py` 후 http://localhost:8765/visual/ — 또는 `visual/index.html`을 바로 열어도 됩니다.
Vercel에 배포되어 있다면 `/visual/` 주소로 열립니다.
