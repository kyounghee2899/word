# 브레인 루틴 (초등 · 하루 10분)

처리속도 · 작업기억 · 실행기능을 **매일 같은 순서의 짧은 루틴**으로 연습하는 웹앱입니다.
설치 없이 브라우저에서 동작하며(휴대폰·태블릿·PC), 학생마다 난이도가 자동으로 맞춰집니다.

- 주소: 배포 사이트의 `/brain/` (로컬: 저장소 루트에서 `python server.py` → http://localhost:8765/brain/ , 또는 `brain/index.html`을 바로 열기)
- 파일: `index.html`(디자인 시스템·스타일) · `ui.js`(아이콘·캐릭터 브레니·진행 링·별점·축하 효과) · `app.js`(루틴·기록·관리 메뉴) · `games.js`(활동 11가지)

## 앱으로 배포·설치 (PWA)
웹앱(PWA)으로 만들어져 있어 **앱스토어 없이 홈 화면에 앱으로 설치**됩니다. 한 번 열면 인터넷 없이도 동작합니다.

1. 이 폴더가 기본 브랜치(main)에 합쳐지면 Vercel이 자동 배포 → `https://(사이트 주소)/brain/`
2. 학생·학부모에게 그 주소를 보냄 (QR 코드로 만들어 교실에 붙여도 됨)
3. 설치
   - 안드로이드·PC(크롬·엣지·삼성 인터넷): 오늘 화면의 **설치** 버튼, 또는 메뉴 ⋮ → 앱 설치
   - 아이폰·아이패드: **Safari**로 열고 공유 ⬆︎ → **홈 화면에 추가** (카톡 안 브라우저에서는 안 됨)

- 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 버전으로 바뀝니다(다음 실행 때 적용).
- 아이폰은 Safari와 설치한 앱의 저장 공간이 따로라, Safari에서 쌓은 기록은 백업 → 불러오기로 옮겨야 합니다.
- 구성 파일: `manifest.webmanifest`(앱 이름·아이콘), `sw.js`(오프라인), `icons/`

## 하루 루틴
| 순서 | 영역 | 시간 |
|---|---|---|
| 1 | 처리속도 1개 | 1분 |
| 2 | 작업기억 1개 | 1~2분 |
| 3 | 실행기능 1개 | 1~3분 |
| 4 | 작업기억/실행기능 번갈아 1개 | 1~3분 |

연습한 날 수에 따라 활동이 돌아가며 나와, 첫 5일 안에 11가지를 모두 만납니다. 루틴 길이는 학생별로 3·4·5개 중에서 고릅니다.

## 활동 11가지
| 영역 | 활동 | 본뜬 과제 유형 | 레벨이 오르면 |
|---|---|---|---|
| 처리속도 | 🔍 기호 찾기 | Symbol Search | 찾을 기호 수·줄 길이·비슷한 기호 증가 |
| 처리속도 | 🔑 기호 암호 | Coding / Digit-Symbol | 암호 개수 4→9, 비슷한 기호, 중간에 암호표 바뀜 |
| 처리속도 | 👀 같을까 다를까 | 지각 비교 | 길이 3→9, 한글 자음 섞기, 자리 바뀜 |
| 작업기억 | 🔢 숫자 기억 | Digit Span (순서·거꾸로) | 맞히면 +1자리, 틀리면 −1자리 |
| 작업기억 | 💡 불빛 순서 | Corsi 블록 (순서·거꾸로) | 맞히면 +1칸, 3×3 → 4×4 |
| 작업기억 | 🧠 몇 개 전 그림? | N-back | 1-back → 2-back → 3-back, 속도 증가 |
| 실행기능 | 🎨 색깔 글자 | Stroop (억제) | 불일치 비율·제한 시간, “뜻 읽기” 규칙 섞기 |
| 실행기능 | 🔄 규칙 바꾸기 | DCCS / 과제 전환 (유연성) | 고정 → 무작위 전환, 제한 시간 |
| 실행기능 | ✋ 멈춰! | Go/No-go (반응 억제) | 속도 증가, 비슷한 유혹 자극, 중간에 규칙 변경 |
| 실행기능 | 🧵 순서 잇기 | Trail Making A/B | 1→16, 1→가→2→나 교대, 방해 동그라미 |
| 실행기능 | 🗼 탑 옮기기 | 하노이의 탑 (계획) | 원판 3→5개, 최소 횟수 조건 |

**적응형 난이도**: 시간제 활동은 정확도 90% 이상이면서 속도 기준을 넘으면 한 단계 오르고, 75% 아래면 내려갑니다. 늘 조금 어려운 수준을 유지하는 것이 목적입니다.

## 화면
- **오늘**: 진행률 링, 연속 일수, 이번 주 7일, 영역별 수준(10점 기준), 학생 전환
- **활동**: 방법 안내 → 3·2·1 → 활동 → 결과(정확도·반응 시간·레벨 변화·💡다음 작전)
- **완료**: 날짜 도장, 스스로 평가(난이도·집중)
- **자유 연습**: 11개 활동을 골라 더 하기
- **기록**: 월 달력, 활동별 레벨 추이(최근 12회), 최근 활동 표
- **관리**(보호자·선생님용, 처음 비밀번호 `0000`): 학생 현황표, **학부모용 주간 리포트 복사**, 루틴 길이·제외 활동·레벨 직접 조정, 백업/불러오기(합치기·덮어쓰기), 엑셀용 CSV
- **안내**: 사용법, 주의사항
